# Baseline Profile — Universe Stream mobile startup path
#
# Human-readable baseline profile. AGP compiles this into the APK at
# assets/dexopt/baseline.prof; profileinstaller triggers install-time AOT
# compilation so first launch and cold starts run the hot startup path
# without JIT warm-up.
#
# Syntax: whole-class rules are bare descriptors (Lcom/pkg/Class;) with NO
# flags — profgen rejects flags on class rules. Method rules would use
# HSPLcom/pkg/Class;->method(...)ReturnType instead.
#
# Scope: classes executed on every cold start before first frame + the home
# screen render. Kept deliberately narrow — over-broad profiles slow down
# install-time dexopt for marginal gain.

Lcom/universestream/app/UniverseStreamApp;
